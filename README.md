# Marketing Campaign Response Prediction

## Project Overview
This project uses machine learning to predict whether a customer is likely to subscribe to a bank term deposit.

## Objective
To develop a predictive model that helps banks identify potential customers for marketing campaigns.

## Dataset
Bank Marketing Dataset (UCI Machine Learning Repository).

## Models Used
- Logistic Regression
- Random Forest

## Application
A Streamlit application that allows users to enter customer details and view a subscription prediction.
